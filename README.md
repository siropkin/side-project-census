# Side Project Census

A year-to-date census of [r/SideProject](https://www.reddit.com/r/SideProject/) — every submission from January 1 to September 13, 2026, classified and counted. Live: https://siropkin.github.io/side-project-census/

Single-file static site: `index.html` holds everything, all charts recompute from the `DATA` object inside it (a copy lives in `data.json`). No framework, no build step for the page itself.

Headline findings: 90,758 projects announced (~355/day), 29.2% wave an AI flag, and the median project gets exactly one upvote.
